# 六种创新机制

### I01：技术、材料或结构迁移

触发：现方案存在明确的性能取舍、结构限制或实现成本。

动作：写明两个难以兼顾的目标；寻找其他品类已使用的原理；说明迁移对象是材料、结构、工艺还是控制方式；列出适配条件和新增代价。

交付：原取舍｜迁移原理及来源｜拟改变的指标｜能力缺口｜最便宜的技术反证。

误判：写“采用新材料、智能、抗菌”而没有具体原理与证据，不合格。创新可以使用成熟技术；不强求发明新技术，也不默认迁移即可量产。

### I02：任务与步骤重组

触发：用户反复准备、分装、寻找、转移、清理或补充。

动作：简列原流程；判断哪一步可以取消、提前完成、由结构承担，或由供应方承担；标出新的责任方和成本。

交付：原步骤→新步骤｜取消或转移的动作｜实现结构/服务｜谁承担新成本。

误判：如果步骤没有减少、顺序没有改善、责任没有变化，只是产品数量增加，就没有证明重组价值。

### I03：场景、人群与价值重新组合

触发：一种产品能力尚未在某类高频任务中被理解或采用，或使用者与付费者关注不同价值。

动作：保留有价值的核心能力；选择明确场景和原点用户；改变形态、交互或呈现，使产品进入另一组真实购买选择；分别说明使用者和付费者为什么接受。

交付：旧场景/比较对象→新场景/比较对象｜必须改变的产品条件｜新的购买理由。

误判：只换年龄、性别或使用地点而没有产品和采用行为变化，不算完成场景迁移。情绪价值可以独立重要，但不能由文案替代产品兑现。

### I04：部件接口与功能组合

触发：多个现成工具共同服务一个任务，却存在接口不兼容、重复搬运或组合后才产生的性能需求。

动作：定义部件间的接口、连接、定位、切换或控制关系；比较单独购买拼凑与整合后的表现；做“去掉连接机制后，价值是否仍一样”的检查。

交付：组成要素｜关键接口｜组合才产生的价值｜兼容边界｜新增复杂度。

误判：同色套装、简单捆绑或“袋子＋盒子＋镜子”本身不证明组合创新。组合应产生可观察的功能协同或任务改善。

### I05：从性能变化到购买标准变化

触发：某项可兑现的性能改变了用户比较和选择产品的依据。

动作：明确旧的选择标准、新的价值要求、相应能力和证明方式；再提出用户能理解的品类描述。

交付：旧标准→新标准｜性能证据｜可理解的名称/表达｜用户理解与选择测试。

误判：先有能力与价值，再讨论名称。自定指标不是行业标准；没有用户认知与选择证据时只称“品类创新假设”。

### I06：交付、渠道或服务组合

触发：产品可做，但用户获取、安装、补充、维护或持续使用困难。

动作：判断可否通过预配置、按需生产、补充件、配送或服务合作消除障碍；明确执行方、响应时间、库存和履约成本。

交付：交付方式变化｜被消除的障碍｜运营依赖｜经济可行条件。

误判：不要给低频耐用品硬加订阅，不把渠道存在当订单，也不要把用户目前没有的食品加工、医疗或配送能力假装成已有资源。

## 通用机制练习

### 练习一：通过结构切换处理冲突

虚构情境：同一工具携带时希望紧凑，工作时希望支撑面积大。
迁移动作：查找可折叠、滑移或展开结构的原理与适配条件，定义携带与工作两种状态。
交付：原取舍 → 连接和定位机制 → 状态变化 → 可观察的任务改善 → 新增重量、夹手与耐久代价。
反证：如果展开费时、支撑不稳或收起后仍过大，技术概念不能证明用户价值。
迁移边界：结构原理需要核查；不能仅凭相似外形断言满足承重或量产要求。

### 练习二：让共用接口取消重复操作

虚构情境：用户在两个工作位置之间逐件搬运、清点并摆放一组工具。
迁移动作：比较现有托盘与带定位关系的共用模块，明确接口如何固定、拆装与兼容。
交付：原步骤 → 共用单元与接口 → 被取消的操作 → 相对普通托盘增加的价值。
反证：如果普通托盘已完成同样任务，新增定位结构只会增加成本和适配负担。
迁移边界：组合需要功能协同；同色套装和共同销售不构成接口创新。

### 练习三：把准备工作转给供应方

虚构情境：用户买到标准部件后还要测量、选配和返工。
迁移动作：探索下单前采集尺寸、供应方预配置、标准接口交付，明确双方责任。
交付：原任务链 → 新任务链 → 责任转移 → 适配错误、交付时间与完整服务成本。
反证：如果采集信息更麻烦、错误率未下降或人工成本过高，应调整或停止。
迁移边界：耐用品不因增加服务就需要订阅；没有重复需求时不套用周期收费。

以上均为方法练习，没有真实用户、商业结果或性能证明。不能作为输入证据引用。
