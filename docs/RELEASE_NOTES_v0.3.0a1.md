# AI Product Idea Validator v0.3.0a1

本版修复“找出机会后未形成具体机制便进入验证”的方法缺口。创新探索衔接A+B，下一步验证围绕具体机制展开；已有方案和纯比较任务保持直接入口。

- 六种机制各包含触发条件、动作、交付与常见误判：技术/材料/结构迁移、任务重组、场景与价值重组、接口协同、购买标准变化、交付与服务组合。
- 机会和概念增加结构化依据链，并在可读报告中呈现。程序检查缺项、机制ID与基本一致性；不把字段完整视为创新成立。
- 无法形成有理由的方向时可返回空候选及下一步；轻量外观修改无需编造技术创新。
- 三个独立入口、项目TXT和API提示词由同一组源文件生成。原完整项目CLI同步加载机制参考，保留其原有分析结构。
- 提供项目资料、可复制指令、三个虚构机制练习及迁移说明。公开示例均为合成数据。

## 升级

包版本为0.3.0a1，属于公开试用版本。项目资料可直接用于对话，不需要API或编程。

基础输入JSON兼容；opportunity和concept输出新增必填innovation对象，输出列表允许为空。validation输出结构保持不变。所有输入摘要随版本变化；旧输出应保留在原运行目录，使用新版本重新prepare/run，不可伪造新摘要绕过检查。

项目用户替换旧资料，并重新保存项目指令。上传固定文件不会自动与仓库同步。仓库main与旧Release标签可以同时存在；选择本版时请核对文件内版本。

## 验证范围

已执行结果见[测试记录](TEST_RESULTS.md)。程序测试、合成示例及作者规则走查用于检查工具实现；不代表独立模型评审、外部用户验证或市场结果。无需先获得商业成功才能试用本工具。
