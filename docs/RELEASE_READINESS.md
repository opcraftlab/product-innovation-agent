# v0.2.0a1 发布自查

状态：已于2026-10-06发布到公开仓库 [opcraftlab/product-innovation-agent](https://github.com/opcraftlab/product-innovation-agent)，作为决策支持工具的公开试用版。检查发布质量与产品商业结果分开；团队实际投入后的市场表现不是本工具开源发布的前置条件。

本工具发布验收聚焦：输出是否忠实于材料；候选是否具有实质差异并能比较；选择理由和资源假设是否清楚；实验动作是否可执行；输入、运行和结果是否可复核。

公开试用版可以在说明实际测试范围后发布。软件稳定版重点完善运行可靠性、失败情境处理、使用体验及已知问题；若宣称具体节省金额或商业成功率，再提供相应真实数据。版本号不评价用户产品的市场成败。
