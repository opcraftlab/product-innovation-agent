# AI Product Idea Validator v0.2.0a1

AI 产品创意评估与验证助手：发现机会、比较方案，制定低成本验证计划。面向产品负责人、创业者和小型产品团队的公开试用版。

## 本版交付

- 三个独立入口：机会发现、产品定义、方向评审与实验设计；可单独使用。
- 18张通用方法卡，按任务加载相关内容。
- 可比较的候选、选择理由、资源与能力假设、风险及下一步实验。
- 无需API的提示词导出与结果导入；可选API运行模式。
- 证据引用、反证、硬约束、预算、输入摘要与历史材料日期检查。
- 中英文说明、合成示例、贡献指南与反馈模板。

## 使用边界

Agent帮助团队准备和比较选择。团队结合资金、人员、时间、供应链和实际操作决定是否投入；市场验证发生在执行端。商业成功不是发布此工具的前置条件。使用者可回填实际结果，继续评审或复盘。
