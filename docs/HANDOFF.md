# 继续开发与交接

本项目可在本地终端、IDE或具备文件读写能力的编程助手中维护。

维护时打开项目根目录，先读 README.md、docs/RELEASE_READINESS.md 和 CHANGELOG.md，再运行测试。关键方法、输入输出约定和使用边界均保存在项目文件中。

当前最近完成：三任务入口、轻量输入、按需方法、证据与预算核查、样例、历史资料日期检查及77项程序测试。实际执行结果以 TEST_RESULTS.md 为准。

已发布仓库：[opcraftlab/product-innovation-agent](https://github.com/opcraftlab/product-innovation-agent)。2026-10-06首次远程CI已通过。继续维护时从该仓库克隆并创建分支；本地发布包可作为离线副本。不能因尚无终端商业结果阻止源码试用发布。

公开试用期间继续完善：真实模型联调、输出质量比较、独立使用反馈。可用已有AI生成JSON后导入，无需强制购买API。实际项目团队若回填投入和操作结果，Agent可继续复盘，但不要求先做真实投资才能使用或发布工具。

首次目标用户暂定中文产品负责人、独立创业者及小型产品团队；通用，未嵌入任何特定企业流程。首发优先方向验证Agent。
